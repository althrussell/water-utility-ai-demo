## Design Context

### Surface type
Databricks App (FastAPI + static HTML/CSS/JS, no build step). It's the "Seqwater Ops Command Centre" front end of the Agent Bricks agent (`ops_agent/ui/cc/`), plus the "Baroon Pocket twin" view (three.js, vendored).

### Audience
Customer-facing field demo. A partner presents it from a laptop browser (often on a meeting-room screen) to Seqwater's CTO and Innovation Executive. It's also reachable from the Genie One mobile app.

### Theme
Light.

### Use case
An executive opens the app to see this morning's proactive insights and KPIs, asks the Operations Agent to investigate one, and approves the action it proposes (work order, regulator notification, briefing).

### Brand (locked)
- Palette: Lava 600 #FF3621 (10% accent), Navy 900 #0B2026, Light #F9F7F4
- Typography: DM Sans 400/500/700 + DM Mono
- Components: Du Bois patterns (custom vanilla components, since the Du Bois package isn't bundled in this external demo)
- Voice: Databricks editorial-plain (no superlatives, plain statements)

### Additional constraints
- WCAG AA.
- Must read clearly at 1440–1920 px on a projector and stack cleanly at 390 px (Genie One mobile).
- The app shows Seqwater's operational data: the product name stays "Seqwater Ops Command Centre", and "Built on Databricks" is the platform attribution.
- Severity has four levels (Critical, High, Medium, Info). Severity must not rely on colour alone.
- Imagery (user-requested): AI-generated editorial and isometric illustrations (GPT Image 2.5) in the Databricks palette, labelled as AI-generated. The twin's bloom layer uses the brand sequential orange ramp.
